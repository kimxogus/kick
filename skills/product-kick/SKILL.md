# 제품 런칭 보조

제품 제작자가 제품의 핵심 강점, 타겟, 셀링 포인트, 등록 문구를 빠르게 정리하도록 돕는다. `product-kick`은 현재 Skill 이름이며, 서비스명 `kick`과 기능명을 혼동하지 않는다.

## 사용할 때

- 제품 등록 초안을 만들 때
- 제품의 핵심 어필 포인트를 찾을 때
- 한 줄 소개, 상세 소개, 태그를 정리할 때
- Product Hunt, Disquiet, 사내 행사 시연용 문구를 만들 때

## 절차

1. 제품명, URL, 대상 사용자, 해결 문제, 주요 기능, 현재 설명 초안을 확인한다.
2. 정보가 부족하면 누락 항목을 질문 목록으로 정리한다.
3. `references/product-registration-workflow.md`를 읽고 출력 형식을 따른다.
4. 과장된 주장, 검증되지 않은 수치, 경쟁사 비방 표현을 제거한다.
5. 결과는 한국어로 작성하되 제품명, URL, 외부 고유명사는 원문을 유지한다.

## 출력

기본 출력은 아래 항목을 포함한다.

- 핵심 어필 포인트 3개
- 타겟 사용자 분석
- 셀링 포인트
- 개선 피드백과 리스크
- 한 줄 소개
- 상세 소개 초안
- 추천 태그
- 런칭페이지 초안
- 카드뉴스 문구
- 채널별 홍보 카피
- 시연 또는 런칭 시 강조할 포인트
- 추가 확인이 필요한 질문
