# 콘테스트 피치 / 포지셔닝 — 킥 (Kick)

> 콘테스트 제출용 요약. 서비스 설명, 핵심 가치, 경쟁력, 심사 영역별 어필 전략.
> 제품 요구사항의 단일 기준은 [SPEC.md](../SPEC.md). 이 문서는 "어떻게 설명하고 어필할지"에 집중한다.

## 1. 한 문장 정의

**"agent에게 말 한마디로 내 제품을 런칭하는, AI 제품을 위한 런칭 플랫폼 — 킥(Kick)."**

- 누가: AI로 제품을 빠르게 만드는 바이브 코더 / 스타트업.
- 무엇을: 제품을 등록·홍보하고, 주간 좋아요로 초기 반응을 얻는다.
- 어떻게: 등록 폼을 직접 채우지 않고, **킥 Skill(추후 MCP)**을 통해 자신의 agent가 대신 올린다.

## 2. 서비스 설명 (엘리베이터 피치)

AI로 제품의 수는 기하급수적으로 늘지만, 만든 사람 대다수는 마케팅을 어떻게 할지 모른다.
Product Hunt는 너무 광범위해 개별 제품이 묻히고, Disquiet는 커뮤니티 중심이라 런칭/발견 동선이 약하다.

킥은 그 중간이다. **제품 런칭과 발견에 집중하되, 댓글·반응으로 가벼운 소통이 되는 곳.**
가장 큰 차별점은 등록 방식이다. 기존 플랫폼은 어필 포인트·카테고리·태그를 사람이 손으로 적어야 한다.
킥은 Skill을 제공해, 제작자가 자기 agent에게 "이 제품 올려줘"라고 말하면 핵심 가치·이름·설명·카테고리를 수집하고 **런칭 페이지·카드뉴스·홍보 카피·타겟 분석**까지 만들어 바로 런칭한다.

## 3. 핵심 가치

### 제작자 (바이브 코더 / 스타트업)

- **홍보 부담 제거**: 마케팅 문구를 몰라도 agent가 대신 작성·등록. 명령만 하면 보장된 품질의 콘텐츠.
- **지속적 채널**: 런칭 이후에도 투자·채용·업데이트 소식을 알리는 통로.

### 뷰어 (탐색자)

- 요즘 제품 트렌드 구경, 나에게 유용한 서비스 발견.
- 경쟁사 분석, 관심 제품에 협업 요청.
- **균일한 고품질 정보**: 직접 홍보는 제작자마다 품질이 들쑥날쑥하지만, 킥을 거친 제품은 모두 보장된 품질의 정제된 소개를 갖는다.

### 플랫폼 (성장 루프)

- 등록 장벽을 Skill로 0에 가깝게 → 콘텐츠(등록 제품) 증가 → 뷰어 유입 → 제작자 유입.
- 등록 마찰 제거가 곧 성장 엔진.

## 4. 핵심 기능

1. **등록 (Skill)**: agent가 말 한마디로 제품 등록. (v1은 Skill + local data, 백엔드 없음.)
2. **보장된 품질의 홍보 콘텐츠**: 런칭 페이지·카드뉴스·홍보 카피가 자동 생성.
3. **Weeklyboard**: 그 주 올라온 제품에 좋아요(무제한) → 주간 랭킹.
4. **Kick Newsletter**: 제작자에겐 댓글·반응 피드백, 유저에겐 주간 인기 제품 큐레이션.
5. **Kick Contest**: 누구나 콘테스트 개최, 상금 표시, 마감일 기준 등록. (MVP는 페이지/플로우만.)

## 5. 경쟁력 (왜 우리가 이기나)

| 축 | Product Hunt | Disquiet | 킥 (Kick) |
| --- | --- | --- | --- |
| 초점 | 글로벌 런칭/발견 | 메이커 커뮤니티 | 런칭/발견 + 가벼운 소통 |
| 등록 방식 | 수동 폼 작성 | 수동 글 작성 | **agent가 Skill/MCP로 자동 등록** |
| 홍보 보조 | 없음 | 없음 | **런칭 페이지·카드뉴스·카피·타겟 분석 생성** |
| 콘텐츠 품질 | 제작자마다 들쑥날쑥 | 제작자마다 들쑥날쑥 | **Skill이 소스 단계에서 품질 보장 → 균일하게 높음** |

**해자(moat)**: 자동 등록은 단순 기능이 아니라 "agent가 마케팅을 대행한다"는 새 등록 패러다임. 경쟁사가 폼을 개선해도 따라올 수 없는 동선 차이.

## 6. 심사 영역별 어필 전략

콘테스트 점수 = 참신성 + 완성도 + 실용성.

### 참신성 — "AI로 이런 것도 돼?"

- **Skill/MCP 자동 등록**: AI가 글을 써주는 걸 넘어, agent가 플랫폼에 나 대신 행동(등록·홍보)한다.
- 명령 한 번에 **런칭 페이지 + 카드뉴스 + 홍보 카피 + 타겟 분석**이 한 번에 나온다.
- 제작자에게는 댓글·반응 기반 **피드백**까지 돌려준다.
- 한 줄: "마케팅을 사람이 하는 게 아니라, agent가 한다."

### 완성도 — "딸깍 이상의 완성도"

- 기존에 존재하는 제품들을 시드로 채워, 마치 킥에서 런칭된 것처럼 연결 → **콘텐츠가 풍부해 보이는** 완성된 화면.
- 심사장에서 **실제로 agent에게 요청하는 장면을 라이브 시연**. (혹시 모를 상황 대비 데모 녹화 백업 준비.)
- end-to-end 루프(Skill 등록 → 런칭 페이지 → weeklyboard 좋아요 → 랭킹)가 끊김 없이 동작.
- 명령만으로 일정 품질이 보장되는 결과물 = "딸깍 이상" 증명.

### 실용성 — "정말 유용한 아이디어"

- **수요는 이미 증명됨**: Product Hunt·Disquiet라는 실제 제품이 존재하니 시장 통증은 검증된 셈.
- **누구나 런칭**할 수 있고, **누구나 정제된 정보**를 얻는다.
- **품질 일관성이 강점**: 직접 홍보하면 제작자마다 품질이 들쑥날쑥하다. 킥은 Skill이 소스 단계에서 일정 품질을 보장해, 플랫폼 전체 콘텐츠가 균일하게 높다.
- 한 줄: "오늘 만든 제품을, 오늘 바로 홍보한다 — 그것도 보장된 품질로."

## 7. 데모 시나리오 (제출용 스토리)

1. (참신성) 발표자가 agent에게 "내 제품 킥에 올려줘" → Skill이 정보 수집 후 런칭 페이지·카드뉴스·카피 생성.
2. (완성도) 등록된 제품이 시드 제품들과 함께 풍부한 목록/상세로 노출, 댓글·좋아요 동작.
3. (실용성) "이번 주" weeklyboard에서 좋아요 → 실시간 랭킹 갱신, 큐레이션된 뉴스레터 미리보기.
4. 마무리: "여러분의 제품도 지금 말 한마디로 올라갑니다."
- ※ 라이브 시연 실패 대비 녹화 데모 백업.

## 8. 열린 질문

- Kick 영/한 표기·로고.
- 데모에서 시드 제품 몇 개를 어떤 카테고리로 채울지.
- AI 큐레이션 필터링 기준(무엇을 저품질로 볼지)을 데모에서 어디까지 보일지.
